# Intelligent-Email-Spam-Detection-Using-Machine-Learning-and-Natural-Language-Processing
ML-based email spam detection system using NLP (TF-IDF) and engineered features. Compares multiple models and deploys the best one with a Gradio interface for real-time spam prediction.

DETAILED REPORT OF PROJECT IS ATTACHED 
DATSET USED IS "Spam Email Dataset" having Labels HAM and SPAM 

ML Algos Used and Result Findings:
Logistic Regression  with 0.957 F1 Score WINNER ,
Random Forest with 0.956 F1 Score , 
Naivee Bayes with 0.817 F1 Score .
